# Fullbody

Приложение с двумя силовыми программами — исходной Full Body и трёхдневным сплитом по системе 5/3/1: ноги и плечи, грудь и трицепс, спина и бицепс. План весов считается от разового максимума, журнал тренировок хранится на телефоне, прогресс рисуется по записям. У каждой программы отдельные история и текущий цикл.

Открывается по ссылке и ставится на домашний экран как обычное приложение. Работает офлайн — в зале связь не нужна.

## Как устроен расчёт

**Базовые упражнения Full Body** (присед, становая, жим лёжа):

```
план = разовый максимум × процент недели × (100 % − снижение)
```

Разовый максимум берётся как больший из двух: введённый вручную и посчитанный по лучшему подходу из журнала (формула Брзицки, до 12 повторов).

**Главные движения сплита** (присед, жим лёжа, становая, жим стоя) считаются по 5/3/1
и работают иначе — не одним весом, а тремя рабочими подходами подряд:

```
рабочий максимум = разовый максимум × 90 % + 5 кг за каждый пройденный цикл
                   (на жимы прибавка 2,5 кг)
вес подхода      = рабочий максимум × процент недели × (100 % − снижение)
```

Проценты по неделям — `65/75/85`, `70/80/90`, `75/85/95`, разгрузка `40/50/60`.
Последний подход первых трёх недель — AMRAP с техническим ограничением: план
показывает минимум повторов, дальше выполняются качественные повторы с запасом
один-два. Настоящий отказ в базовых движениях не требуется.

Запас в 10 % между разовым и рабочим максимумом и есть причина, по которой
`95 %` в третьей неделе — это лишь около `85 %` настоящего максимума. Тяжёлая
работа идёт без предельных попыток каждую неделю.

Растёт программа не от рекордов, а по расписанию: прибавка за цикл заложена в
самой системе. Результат AMRAP влияет на график расчётного максимума, но не
переписывает Training Max и поэтому не создаёт вторую прибавку веса.

Каждый подход записывается отдельно. Кнопка «Готово» сохраняет плановый вес и
повторы одним касанием; для другого результата вес и повторы выбираются
прокручиваемыми барабанами.

**Подсобка** — от лучшего рабочего веса в этом упражнении, с тем же снижением.

## Под что собрана подсобка

Силовое ядро 5/3/1 менять нельзя, а подсобка в этой системе выбирается под цель.
Цель здесь — ширина плечевого пояса при узкой талии, поэтому широчайшие и бицепс
получают и больший объём, и вторую работу за неделю:

| Мышца | Подходов в неделю | Сколько раз в неделю |
|---|---|---|
| Широчайшие | 15 | 2 |
| Бицепс | 13 | 2 |
| Грудь | 9 | 1 |
| Трицепс | 6 плюс жимы | 1 |
| Средние и задние дельты | 6 | 1 |

Вторая работа спины и бицепса стоит в дне груди — он был самым коротким.
Место под неё освободило разгибание рук на блоке: оно повторяет жим узким
хватом, а французский жим оставлен, потому что только он грузит длинную головку
трицепса в растянутом положении.

Талию тренировкой не сузить, это питание. Пресс здесь нужен для корпуса,
а не для рельефа, и работает без веса.

Результат округляется под реальное железо: штанга шагом 2.5 кг и не легче грифа, гантели 2 кг, блоки 5 кг. Шаг настраивается.

## Снижение после перерыва

Одна настройка на всё приложение: на сколько снизить веса, пока не вернулся в форму — 0–30 %. После долгого перерыва ставишь 20 %, вся программа пересчитывается сразу. Втянулся — возвращаешь на 0.

Это заменяет ручной пересчёт программы после каждой паузы.

## Данные

История лежит в localStorage браузера. Для приложений, добавленных на домашний экран, Safari не применяет очистку по 7 дням, но копию всё равно стоит сохранять — кнопка «Сохранить копию» на вкладке «Настройки» выгружает всё одним JSON-файлом.

## Структура

| Файл | Что делает |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `source/program.json` | программа Full Body: неделя, день, упражнение, подходы, повторы, проценты |
| `source/split.json` | трёхдневный сплит 5/3/1: волна процентов по неделям, прибавка за цикл, состав дней |
| `data.js` | сгенерированные данные, которые читает приложение |
| `gen_data.py` | собирает `data.js` из `source/program.json` и справочника железа |
| `sw.js` | service worker, кэш для работы офлайн |

Зависимостей нет, сборка не нужна.

Личных цифр в репозитории нет. Максимумы и рабочие веса живут только на телефоне — при желании их можно положить в `personal.json` (не коммитится), тогда `gen_data.py` соберёт `starter-fullbody.json` для загрузки в приложение:

```json
{
  "maxes": { "Приседания со штангой": 000 },
  "lastWeights": { "Молоток": 00 },
  "deload": 0.2
}
```

## Разработка

```bash
python gen_data.py
```

Перегенерирует `data.js` после правки программы. Дальше открыть `index.html` в браузере — этого достаточно.
