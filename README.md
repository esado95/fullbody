# Fullbody

Приложение для силовой программы: план весов считается от разового максимума, журнал тренировок хранится на телефоне, прогресс рисуется по записям.

Открывается по ссылке и ставится на домашний экран как обычное приложение. Работает офлайн — в зале связь не нужна.

## Как устроен расчёт

**Базовые упражнения** (присед, становая, жим лёжа):

```
план = разовый максимум × процент недели × (100 % − снижение)
```

Разовый максимум берётся как больший из двух: введённый вручную и посчитанный по лучшему подходу из журнала (формула Брзицки, до 12 повторов).

**Подсобка** — от лучшего рабочего веса в этом упражнении, с тем же снижением.

Результат округляется под реальное железо: штанга шагом 2.5 кг и не легче грифа, гантели 2 кг, блоки 5 кг. Шаг настраивается.

## Снижение после перерыва

Одна настройка на всё приложение: на сколько снизить веса, пока не вернулся в форму — 0–30 %. После долгого перерыва ставишь 20 %, вся программа пересчитывается сразу. Втянулся — возвращаешь на 0.

Это заменяет ручной пересчёт программы после каждой паузы.

## Данные

История лежит в localStorage браузера. Для приложений, добавленных на домашний экран, Safari не применяет очистку по 7 дням, но копию всё равно стоит сохранять — кнопка «Сохранить копию» на вкладке «Настройки» выгружает всё одним JSON-файлом.

## Структура

| Файл | Что делает |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `source/program.json` | программа: неделя, день, упражнение, подходы, повторы, проценты |
| `data.js` | сгенерированные данные, которые читает приложение |
| `gen_data.py` | собирает `data.js` из `source/program.json` и справочника железа |
| `sw.js` | service worker, кэш для работы офлайн |

Зависимостей нет, сборка не нужна.

Личных цифр в репозитории нет. Максимумы и рабочие веса живут только на телефоне — при желании их можно положить в `personal.json` (не коммитится), тогда `gen_data.py` соберёт `starter-fullbody.json` для загрузки в приложение:

```json
{
  "maxes": { "Приседания со штангой": 000 },
  "lastWeights": { "Молоток": 00 },
  "deload": 0.2
}
```

## Разработка

```bash
python gen_data.py
```

Перегенерирует `data.js` после правки программы. Дальше открыть `index.html` в браузере — этого достаточно.
